# Style Lock — shared preamble for all concept-art prompts

**Current sourcing method: manual ChatGPT generation (DECISIONS.md #023).** All 22 image assets use the illustration prompts in `prompts/assets.json` (`prompt` field) and `prompts/remaining_18_prompts.md`, generated by hand outside this session and dropped into `assets/images/` under the Asset Register's filename convention.

## Preamble text (prepended to every per-asset prompt)

> Cinematic digital illustration, Tron-adjacent cyber-noir aesthetic for a military OSINT training environment. Near-black base tones (#0A0B0E), cyan/electric-blue neon grid-line accents (#26E5FF), hot-pink/magenta neon signage glow (#FF2FB0), amber accent lighting on interactive/functional elements (#FFB020). Subtle scan-line / VHS grain atmosphere. Moody, high-production-value, restrained — not campy or garish. Rain-slicked reflective surfaces where exterior. Widescreen 16:9 composition, no on-image UI chrome, no watermarks, no readable real-world logos or brand marks, no depiction of real identifiable people's faces.

## Source
Derived from [UI_Style_Guide.md](../docs/UI_Style_Guide.md) §1 (palette), §3 (texture), and [Creative_Bible.md](../docs/Creative_Bible.md) §2 (world & tone), §4 (sensitivity rules for case-study rooms).

## Sensitivity constraint (applies to SG001, FC001, GA001)
Per Creative Bible §4: no real individuals, no invented details beyond what the source deck states, environmental/symbolic framing only — never a generated portrait standing in for a real person or an invented scene of an incident's mechanics.

## Aspect ratio / size
Landscape, `1536x1024`-equivalent framing for all 22 assets.

## Superseded paths (kept for reference, not currently used)
Two earlier sourcing approaches were tried and abandoned in favor of manual ChatGPT generation — nothing below is wired into the current pipeline:
- **Gemini API (Imagen/native image models)** — `scripts/generate_images.py` exists and authenticates correctly, but the account's free tier has a hard 0 quota for image models (DECISIONS.md #020/#021). Revisit if billing is enabled later.
- **Unsplash stock photography + CSS/SVG overlay** — explored as a hybrid (DECISIONS.md #021/#022: real photo backgrounds, bespoke signage/text rendered as an overlay layer per Component_Specification.md C-1). API keys are configured in `.env`, but **no `scripts/source_images.py` was ever built** — the plan changed before that script was written. `assets.json`'s `overlayText`/`searchQuery` fields from that phase were folded back into `prompt` when DECISIONS.md #023 reverted to ChatGPT-manual for all 22.
